# Organizador de Texto Offline para BOs em Caixa Alta

Página estática para formatar textos de boletins de ocorrência, sem análise jurídica.

## Uso
- **Online:** quando o GitHub Pages estiver ativado, acesse https://delta369369.github.io/Token-free/
- **Offline:** baixe `index.html` e abra no navegador, sem instalação.

## Recursos
- Importação de PDFs digitais (texto selecionável), TXT e DOCX.
- Identificação de comunicantes, vítimas, suspeitos e testemunhas, com campos de qualificação quando presentes.
- Capitalização, preservação de siglas e organização da narrativa em parágrafos.
- Remoção de marcas numéricas repetidas, cabeçalhos de validação, assinaturas eletrônicas e rodapés.
- Área de edição livre, botão para copiar, salvar TXT e limpar.

## Privacidade e limitações
O conteúdo é processado localmente no navegador; **não publique boletins reais ou dados pessoais no repositório**. O download inicial da página hospedada usa internet, mas o processamento dos arquivos não os envia a um servidor. PDFs digitalizados como imagem precisam de OCR, não incluído. Confira a extração dos dados no boletim original.
